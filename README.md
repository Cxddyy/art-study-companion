# Art Study Companion

一个艺术学习与创作助手 Skill，用于分析艺术作品、梳理艺术史、生成课堂展示大纲和创作灵感框架。

作者：Cxddyy

## 适用场景

- 艺术作品分析
- 艺术史知识梳理
- 课堂展示与小组汇报准备
- 艺术评论与作品解读
- 创作灵感整理
- 展览或作品集说明框架生成

## 安装方式

将仓库克隆到本地后，把 `art-study-companion` 文件夹放入对应工具的 Skills 目录即可。
